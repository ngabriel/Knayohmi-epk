Welcome

Congratulations on your purchase. Your EPK is fully yours. There are no subscriptions and you keep the full website code and content.

You do not need to know how to code to use this product. The website structure is already built — you simply replace the demo content with your own information.

What this is

Your EPK is a website designed to give promoters, bookers and venues one simple place to find your DJ information.

What it includes

Bio, mixes, press highlights, video, photos and booking contact.

Why it matters

A professional EPK makes it easier for promoters to understand your style and book you for events.

How it works

Your EPK works using three simple parts:

1. Website structure

This controls the design and layout of your EPK. You own this code but you don't need to edit it.

2. Your content

Your DJ name, bio, links and videos are stored in one file called data.json.

3. Hosting

Hosting simply means putting your website online so people can visit it. We will use GitHub Pages because it is free and reliable.

Your website address

When first published your site will have a GitHub address. 

yourusername.github.io/your-epk

You can also connect your own domain later for something more professional:

www.yourdjname.com/epk

What is GitHub?

GitHub is a free online platform that stores your website files and lets you publish your website online.

For this guide, you can think of GitHub as the home for your EPK. It is where your website lives and where you will update your content.

We will use GitHub for two things:

  • storing your website files
  • publishing your website online

Setting up GitHub

I recommend using Google Chrome for setup.

  1. Create a free account on GitHub
  2. Sign in to your account
  3. Go to the EPK template repository
  4. Click Use this template
  5. Click Create new repository

This creates your own copy of the website inside your GitHub account.

Inside the repository you will see all the files that make up your website.

Important: the only file you normally need to edit is data.json.

Publishing your site

Video walkthrough:

[Add how-to video link here]

Before editing the content we will publish the website so you can see your changes live.

  1. Open your repository
  2. Click Settings
  3. Click Pages
  4. Set Source to Deploy from branch
  5. Set Branch to main
  6. Set folder to /root
  7. Click Save

After a few minutes your website link will appear.

Refresh the page if it does not appear immediately.

Before you start editing

Before updating your EPK, it helps to have your main information ready.

  • Your DJ name
  • A short tagline
  • A short bio
  • Your Instagram and SoundCloud links
  • Your YouTube or video link
  • Your press highlights or key gigs

Having these ready will make the setup much quicker and easier.

Understanding data.json

This is where all the magic happens.

Don’t worry if this looks technical at first. In most cases, you will only be changing words, links and text.

The file data.json controls all the content on your EPK website.

Instead of editing the website code, you simply edit the information inside this file.

The website then reads this file and displays the content on your page.

The technical part

This is the only slightly technical part of the process — but don’t worry, you only need to make small text changes.

The data.json file is written in a format called JSON.

JSON uses symbols like these: 

{
              }
              "
              :
              ,

These symbols are important because they define the structure of the file.

When editing the file, be careful not to remove them.

  • Do not remove brackets { }
  • Do not remove quotation marks "
  • Do not remove commas ,

If one of these is missing, the file may break and the website will not update correctly.

How JSON works

JSON is written in pairs: 


        keyword : content

Example:


        "artistName": "KNAYOHMI"

The first part is the keyword. The second part is the content.

You only edit the content. The keywords must stay the same because the website uses them to find the correct information.

Saving your changes

After editing your file in GitHub, scroll to the bottom of the page and click Commit changes.

This simply means save your changes.

Once saved, GitHub updates the new version of your file and your website will refresh with the new content.

If your changes do not appear straight away, wait a few seconds and refresh your website.

Let’s make our first edit

Now we are ready to start editing the first part of your EPK.

We will begin with the header section.

This section controls:

  • your DJ name
  • your tagline

This will be the first step in turning the demo profile into your own EPK.

Editing your header

The header contains your DJ name and tagline.

"header": {
            "artistName": "KNAYOHMI",
            "artistTag": "South London DJ • House / Tech / Funk / Afro-Latin / Disco"
          }

artistName

Your DJ name.

Example: DJ Luna

artistTag

A short description of your style.

Examples:

  • London DJ • House / Disco
  • Berlin DJ • Techno / Minimal
  • Ibiza DJ • House / Tech House

Keep this short and clear.

Hero section

The hero section is the main introduction text at the top of your EPK.

"hero": {
            "title": "Keep it moving, keep it grooving.",
            "lead": "Groove-led, soulful and techy sets rooted in funk, disco, and house — built for connection, freedom, and letting go.",
            "pills": ["London, UK", "House / Disco / Afro-Latin Grooves", "Residencies + bookings"]
          }

title

A short statement describing your music.

Example: Dancefloor energy from start to finish.

lead

A short paragraph describing your DJ style.

pills

Small highlight tags displayed under your introduction.

  • London, UK
  • House / Tech House
  • International bookings

You can add or remove items inside the list.

Bio section

The bio section allows you to store multiple versions of your biography.

This is useful because different promoters request different lengths.

"bio": {
            "title": "Bio",
            "helpText": "Choose the version you need. Download as text in one click.",
            "versions": {
              "short": "Short bio text goes here...",
              "long": "Longer bio text goes here...",
              "full": "Full professional bio text goes here..."
            }
          }

Short bio – 1–2 sentences for quick introductions.

Long bio – one paragraph.

Full bio – longer biography for press or festivals.

Press section

This section highlights important events, residencies and appearances.

"press": {
            "sectionTitle": "Press & highlights",
            "residencyTitle": "Residencies",
            "residencies": [
              "STICKYJAM Music — South London Tech House Party"
            ]
          }

Residencies

Clubs or events where you regularly perform.

Appearances

Important events or gigs you have played.

Video section

This section introduces your DJ set video or showreel.

"video": {
            "title": "Video",
            "helpText": "Live clips and showreel."
          }

Your video will normally be embedded from YouTube or Vimeo.

Recommended content:

  • DJ set recording
  • Showreel
  • Live performance clip

Contact section

The contact section allows promoters to book you quickly.

"contact": {
            "title": "Booking",
            "helpText": "Give me a message - I promise I won't bite!",
            "email": "hello@naomigabriel.com",
            "instagramUrl": "https://instagram.com/knayohmi",
            "soundcloudUrl": "https://soundcloud.com/knayohmi"
          }

Email – your main booking email.

Instagram – your main social profile.

SoundCloud – your mixes or music.

Important tips

  • Only change text between quotation marks
  • Do not remove commas
  • Do not remove brackets
  • Save the file before refreshing your website

If something breaks, it is usually caused by a missing comma or quotation mark.

Example JSON structure

{
  "header": { ... },
  "hero": { ... },
  "bio": { ... },
  "press": { ... },
  "video": { ... },
  "contact": { ... }
}

Each section corresponds to a different part of your EPK page.

As you edit your content, you will be updating the values inside these sections.

FAQ

Can I use my own domain?
Yes. You can connect your own domain later. You only pay for the domain name itself.

Do I need to edit code?
No. Most users only need to update content in data.json.

Can I host it somewhere else?
Yes. Because you own the files, you can host your EPK anywhere that supports static websites.
